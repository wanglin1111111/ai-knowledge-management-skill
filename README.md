# AI 知识管理技能包

把散落在不同来源、不同格式的信息，整理成可检索、可溯源、可关联、可再生成的知识资产。包含 4 个核心技能。

## 核心技能

### 1. 多源异构文档整合

将 PDF、网页、Markdown 笔记、图片截图、视频链接等统一导入知识库，形成结构化知识网络。适用于学术研究、竞品调研、个人学习与知识沉淀。

### 2. 可溯源知识检索

AI 回答时给出具体文档、页码与段落位置，支持跳转到原文高亮处。适用于法律、学术、商业分析与医疗等需要核对出处的场景。

### 3. 跨文档关联分析

同时处理多份文档，识别观点继承、矛盾冲突与潜在共识，发现线性阅读难以察觉的隐性关联。适用于文献综述、竞品对比、政策梳理与理论建构。

### 4. 多模态内容生成

基于知识库内容生成可编辑 PPT、双人对话播客、信息图与思维导图，把「读过的资料」转成「可交付的知识产品」。

## 使用方式

将目录放入 Agent 的 skills 目录，在需要处理大量资料的任务中加载。使用前先确认所选工具是否支持**引用锚点**与**多格式解析**，否则「可溯源」无法兑现。

## 适用对象

学术研究者、知识工作者、终身学习者，以及需要处理大量异构信息的专业人士。
